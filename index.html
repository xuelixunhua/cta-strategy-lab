01 / 假设

赚什么钱

趋势延续，还是偏离后的回归？不同假设可能对同一条布林线给出相反动作。

02 / 信号

何时买卖

先把含糊判断变成可计算条件。不要把当根收盘信号当作当根开盘前已知。

03 / 仓位

承担多少风险

本版按入场权益分配固定名义仓位；期货取整数手。同一个信号，仓位不同，风险也不同。

04 / 执行

以什么价格成交

下一根开盘、手续费、滑点、零成交量检查；期货实际合约移仓另计双边交易成本。

05 / 风控

何时离场与等待

正常退出、空仓状态、ATR保护性止损各有职责。跳空时不能保证按止损线成交。

06 / 研究

怎样辨别有效性

逐笔复盘、同口径基准、成本后表现、参数附近与不同时间段，而不是只盯历史最高收益。

单SMA → EMA → 双均线 → 空仓 → 布林 / SF01 / SuperTrend
入场、退出和仓位是独立模块；复杂不等于更赚钱。吊灯、百分比及波动率倒数可以单独对照。

基本面、情绪面可以在更完整的体系中解释环境、调整风险预算或过滤交易；本实验室不冒充已经实现这些部分。

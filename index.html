相同标的、窗口、仓位与成本。双均线周期独立设置；这不是参数最优比赛。

EMA更敏感不等于更赚钱；双均线也不天然拥有空仓。观察收益、回撤、交易次数、空仓比例的共同变化。

同一个入场想法，怎样退出才合适？

固定入场规则、参数、窗口和成本，仅替换退出部件；后续入场时间可能随持仓状态改变，不是逐笔配对实验。

吊灯与ATR倍数：波动越大，价格距离越宽。波动率倒数实验：ATR/价格越大，允许回撤比例越小。两者不是同一种逻辑；本版全部退出保护线只在收盘后更新，并单向收紧。

好参数应是一片区域，而不是一个孤点。

按时间先后划分70%研究段与30%验证段；每段重新从现金开始，指标可用此前历史预热。

这里只做相邻周期的敏感性诊断，不自动选赢家。反复看过验证段后，它就不再是未接触的样本外；还需要新的时间段和品种。

THE TRADING SYSTEM

指标只负责描述，
规则与执行才组成系统。

一个完整的技术系统，不只回答“什么时候买”，还必须回答买多少、何时不做、错了怎么办、如何确认自己没有看错历史。

01 / 假设

赚什么钱

趋势延续，还是偏离后的回归？不同假设可能对同一条布林线给出相反动作。

02 / 信号

何时买卖

先把含糊判断变成可计算条件。不要把当根收盘信号当作当根开盘前已知。

03 / 仓位

承担多少风险

本版按入场权益分配固定名义仓位；期货取整数手。同一个信号，仓位不同，风险也不同。

04 / 执行

以什么价格成交

下一根开盘、手续费、滑点、零成交量检查；期货实际合约移仓另计双边交易成本。

05 / 风控

何时离场与等待

正常退出、空仓状态、ATR保护性止损各有职责。跳空时不能保证按止损线成交。

06 / 研究

怎样辨别有效性

逐笔复盘、同口径基准、成本后表现、参数附近与不同时间段，而不是只盯历史最高收益。

单SMA → EMA → 双均线 → 空仓 → 布林 / SF01 / SuperTrend
入场、退出和仓位是独立模块；复杂不等于更赚钱。吊灯、百分比及波动率倒数可以单独对照。

基本面、情绪面可以在更完整的体系中解释环境、调整风险预算或过滤交易；本实验室不冒充已经实现这些部分。

# CTA Strategy Lab

从一根均线到一套可解释的技术交易系统：观察问题、改变规则，再回到每一笔实际历史交易验证。

[打开实验室](https://xuelixunhua.github.io/cta-strategy-lab/) · [v1.2工作区与学习流程](docs/WORKSPACE.md) · [部署说明](docs/DEPLOYMENT.md)

## 1. v1.2：看图和看懂决策

前端1.2.0保留引擎1.1.0的行情与账目算法。设置面板可收起；K线、指标、净值和回撤同图显示，共用时间轴、独立纵轴。框选、平移、精确区间与专注模式只改变视图，不修改回测窗口或收益。

每个策略分别提供小时/日线固定教学预设，并能恢复或保留自定义参数。只有真正存在两套价格坐标的期货连续数据提供切换，其他情况直接解释口径。

教学主线变为“假设→入场→持有与仓位→退出→再入场→验证”。每课说明为什么改、改了什么、代价是什么；可以定位失败交易、同口径对照前一步、保留入场单独更换退出。决策回放列出真实信号数值、成交价格、退出触发和成本，不只展示一段泛泛的策略介绍。

## 2. 策略与退出不是排行榜

| 基础规则 | 研究问题 |
|---|---|
| 单SMA / 单EMA | 近期权重、滞后与震荡磨损 |
| 双均线交叉 / 加空仓 | 平滑方向，分开退出与反手 |
| 布林突破 / 布林回归 | 同一指标承载不同交易假设 |
| SF01教学通道 | 改变OHLC构造的突破边界 |
| SuperTrend | HL2＋Wilder ATR与KAMA＋滚动ATR的明确版本 |

独立退出含收盘ATR、吊灯、百分比和波动率倒数实验，可叠加或替换原退出，并控制保护退出后的再入场。更复杂不代表更有效；不同退出会改变后续实际交易集合。波动率倒数明确属于实验定义，不是逆波动率仓位。

## 3. 数据和公开范围

原有快照共52个标的、89组标的×周期：BTC/ETH现货、7个A股指数、8个美股/ETF/指数、34个JM实际合约及1个教学连续系列；不是52个独立期货品种。缺少小时源的标的不提供小时切换。

焦煤信号价格采用因果比例衔接，盈亏按实际合约平旧、开新并计两侧成本；有限样本不能称官方主力连续。股票/ETF全部OHLC统一调整，指数属于不可直接成交的价格代理。窗口最后的估值平仓与普通策略退出分别标记。

本项目是独立教学实现，不镜像私有框架、配置、账户、凭证或Git历史。代码与原创说明为MIT许可，行情不在MIT范围；再分发权利由发布者按来源条款确认。[数据政策](docs/DATA_POLICY.md)

## 4. 构建与发布

Pages已配置为GitHub Actions，根目录已有固定哈希的 `cta-public-ohlc-export.zip`，无需重新上传数据或更改Pages设置。新提交使用原工作流重建89组行情、测试并部署；以上线对应提交的Deploy步骤成功为准。

本地构建按[部署说明](docs/DEPLOYMENT.md)执行；存在完整data目录后运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。浏览器不需要账号或API密钥，所有回测在本地执行，无实盘下单。

## 5. 验证与文件职责

```bash
node --test tests/*.test.js
node scripts/audit_data.js
node scripts/build_cases.js
node scripts/build_exit_cases.js
```

v1.2本地45项单元测试、56项离线浏览器交互检查、89组数据的1,602次全历史实现检查通过，范围见[工作区说明](docs/WORKSPACE.md)。这些不是策略收益或实盘成交能力的证明。

`engine.js`管理规则与账目；`charts.js`只绘图；`study.js`定义固定预设和教学流程；`workspace.js`和`app.js`管理交互；`scripts/`重建数据及案例；`tests/`校验实现；`docs/`记录口径与边界。

仅供研究教学，不构成投资建议。未模拟完整订单簿、涨跌停可成交性、历史保证金强平、借券与资金费，不能直接作为实盘系统。

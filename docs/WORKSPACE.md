# 从规则到决策：v1.2 工作区

前端版本 1.2.0，回测引擎仍为 1.1.0。本次改变交互与讲解，不修改历史行情、成交、复权或盈亏算法。上线状态以当前提交的 Pages 部署记录为准。

## 1. 先看清楚，再调参数

设置完成后点“运行并收起设置”，或顶栏“收起设置”。图表使用释放出的宽度；“专注看图”让同一张图占满浏览器工作区，Esc 或图内按钮退出。讲解也可以单独收起。

K线、信号线、策略净值、回撤在同一张Canvas、同一时间轴中显示，可独立勾选；持续做多基准默认关闭。价格、净值、回撤单位不同，使用独立且明确标注的纵轴，曲线视觉相交不代表同一数值。手机将回撤百分比刻度放在图内，不挤占额外纵轴宽度。

默认拖动框选时间段；切到“平移”可拖动图形。滚轮缩放，Shift拖动临时框选，撤销返回上一次视图，双击或“全览”显示完整回测窗口。“精确查看区间”支持日线日期和小时线时分。小时线币圈采用UTC，期货采用北京时间。

**查看区间不等于回测区间。** 框选、平移、隐藏图层、价格坐标切换均不重新计算收益，不改变交易集合。净值不因缩放归一到1，回撤沿用完整回测历史高点。重新回测要在设置面板改开始/结束交易日并运行。

只有存在不同衔接比例的期货连续数据提供“信号价/原合约价”切换。现货、单合约、统一调整价格代理没有可展示的第二套曲线时，显示原因和口径说明，而非一个看起来无反应的按钮。切换时K线、指标和保护线共同映射；账目不变。

## 2. 固定预设：开箱观察，不代表最优

| 策略/模块 | 日线预设 | 小时线预设 |
|---|---|---|
| 单SMA、单EMA | N=20 | N=48 |
| 双均线、双均线加空仓 | 10/40 | 24/96 |
| 布林突破、布林回归 | N=20，K=2 | N=48，K=2 |
| SF01教学通道 | N=20 | N=48 |
| SuperTrend | HL2，ATR10×3 | HL2，ATR24×3 |
| 独立ATR/吊灯退出的初始设置 | ATR14×3；吊灯窗口22 | ATR24×3；吊灯窗口48 |

初始不启用独立退出，先观察原生规则。百分比退出为5%；倒数实验的上下限为1%/20%。这些数值不根据行情自动寻优，也不承诺相同时钟跨度或跨市场风险相等。

切换策略或时间级别自动载入相应参数；“保留自定义参数”勾选后可固定自己的设置。“恢复本课默认”不重置本金、费用或仓位。切换数据集的日期/方向仍由该数据集决定；共享URL携带的已保存参数优先于启动预设。

## 3. 为什么演进，而不是为什么多一个指标

每课先展示“为什么改—本课改什么—代价与边界”，再沿六环节展开：**假设 → 入场 → 持有与仓位 → 退出 → 再入场 → 验证**。执行时点与成本贯穿入场、退出和账目。

SMA建立可执行基准；EMA改变近期权重；双均线改变方向信号的平滑程度；加入空仓拆开方向与退出。通道突破、SF01和SuperTrend是需要比较的分支，不构成效果必然递增的阶梯。布林回归是另一种收益假设，不是突破策略的高级版。

“与前一步对照”固定当前周期、仓位、成本、窗口和退出模块，展示两套规则的净收益、回撤和交易数。SF01原生退出与布林不同、回归假设与突破不同，页面明确说明并非严格单变量因果实验。

“定位一笔非盈利交易”从当前实际交易中选择非估值样本；没有这类交易时说明并退回已有样本，不虚构失败案例。“保留入场，试吊灯退出”保持当前入场参数，改为吊灯替换原退出并等待同方向条件失效后再出现。退出改变占仓状态，后续入场集合可能改变，不冒充严格逐笔配对。

## 4. 逐笔、逐根核对退出

决策回放给出实际入场信号价格与阈值、下一可交易开盘的参考/模拟成交价和数量、实际退出触发、毛盈亏减成本后的净额。普通退出、事先确定保护线的盘中触及、跳空越线、窗口末尾估值分别解释。

保护退出使用引擎记录的该根事先可用线，不用这根最高价事后倒推。最后一根估值不冒称趋势失效。原始合约价与信号坐标明确区分。点击“看入场信号”“看退出触发”或“整笔交易”定位图形；点击一根K线则查看它真实记录的持仓、指令与成交。

建议第一轮只做：SMA定位失败交易 → EMA同口径对照 → 双均线加空仓理解等待 → 布林突破固定入场、替换吊灯 → 核对某笔退出前一根的保护线。能解释为什么交易、为什么等待，才进入寻参研究。

GitHub Actions继续执行 `node --test tests/*.test.js` 和数据审计。`assets/study.js` 管纯教学定义与预设，`workspace.js` 管新交互，`charts.js` 仅绘图，`app.js` 协调数据和现有实验，`engine.js` 保持原规则与账目。界面构建通过不代表策略有收益优势或实盘可成交性。

# 策略与退出定义 · v1.1

## 1. 新增入场规则

**SF01通道（教学版）**：源研究笔记有 `U=O+H-C`、`D=O+L-C`，再取N周期最高U、最低D。本项目第t根阈值仅使用t-1及此前N根已完成K线。收盘突破上轨做多、跌破下轨做空。默认在持仓方向的对侧边界被收盘突破时平仓。原笔记只给出通道构造，本项目的平仓、仓位和执行是教学补全，不声称复刻某个未核实的完整SF01策略。它不是简单的影线长度，O和C同时参与变换。

**SuperTrend**提供两种明确版本。HL2版本以(H+L)/2为中心，ATR采用Wilder平滑，收盘价格突破上一根反向带切换趋势。KAMA研究变体以KAMA为中心、用KAMA突破上一反向带切换趋势，ATR使用简单滚动均值；这一结构来自已核读研究实现。两者都只在收盘后更新状态，次根开盘执行。不是一个名称对应唯一公式。

共同递推：上带若上一参考价≤上一上带，则取当前基本上带与上一上带的较小值，否则重置；下带方向相反。参考价达到前上带切多，严格低于前下带切空，否则保持趋势。首个完整窗口初始化方向为C≥中心时多，否则空。

KAMA使用N根收盘均值初始化，快/慢平滑固定2/30；效率比为N根净位移/逐根绝对位移总和，平滑系数为快慢系数的效率比插值再平方。与原研究代码的0值初始化和不完整预热不同，不能认为逐点完全一致。

## 2. 退出方法

价格均处于同一信号价格坐标，多头公式如下，空头对称。

| 方法 | 收盘后计算的下一根候选线 | 解释 |
|---|---|---|
| 原策略 | 原规则自己的收盘退出信号 | 次根开盘执行 |
| 收盘ATR | C_t - k ATR_t | 收盘锚定；不是吊灯 |
| 吊灯 | 持仓内最近L根最高H - k ATR_t | 入场前高点不参与，空头取最低L |
| 百分比 | 入场后最高H × (1-d) | d是价格回撤比例，不是利润回吐比例 |
| 波动率倒数（实验） | 入场后最高H × (1-d_t) | 下述明确公式，不是行业标准或原框架忠实复刻 |

所有保护线单向收紧：多头取旧线与候选线较高者，空头相反。吊灯旧极值滚出窗口、ATR变大或波动率下降，都不能放松已有保护线。入场首根ATR/吊灯保护线为入场价格减已知ATR倍数；百分比为入场价减比例。不会用入场前的极端行情生成一条可能位于入场价格另一侧的“止损”。

波动率倒数实验：`v_t=ATR_t/|C_t|`；`v_entry`在入场之前的已知收盘固定；`d_t=clip(d_base*v_entry/max(v_t,1e-9),d_min,d_max)`。默认d_base=5%，上下限1%/20%。例如入场ATR%=2%，后来升为4%，候选回撤比例从5%降为2.5%；波动越大反而越紧。这与k×ATR距离的变化方向不同，也与仓位∝1/波动率不同；可能在波动扩张中反复被洗出，必须视为待检验假设。零波动样本依上下限约束处理，不外推无限宽度。

## 3. 组合与再入场

**叠加**：保留原正常退出，另加保护线，按执行时序先发生者退出。**替换**：持仓期间忽略原正常退出及反转，只等独立保护线；风险事件、数据缺口和窗口末尾估值仍优先。

保护退出后可选“条件持续即可再入场”或“先失效再出现”。后者为新增保护模块默认值：被止损的同方向入场条件需要先在某次收盘失效，才能在之后恢复时入场；反方向条件不受该方向锁限制。否则止损后下一根又因为同一持续突破信号买回，会把退出实验变成高频反复入场。

这两种选择都不能声称最优。退出对比固定入场算法而不是固定每一笔实际入场时间：不同出场改变占仓，因此后续交易集合会变化，不能将全系统对照误称严格逐笔配对实验。

## 4. 时序、图形与账目

盘中只能触发上一根收盘后已确定的保护线。本根最高点不能生成一条在同根低点被理想触发的线。若收盘更新后保护线已经穿过收盘价，也只会在下一开盘按实际更差价格退出。跳空穿线按开盘，不按理想止损价。没有tick路径的止损K线不记完整高低点为可确认MFE/MAE。

保护线与K线同坐标显示，原始期货图按当前衔接比例同时映射全部指标。期货换月仍按真实旧腿、新腿核算并计各侧成本；新旧合约价差不记为收益。

## 5. 验证与来源范围

新增测试覆盖SF01变换与滞后一根、两版趋势预热、未来数据前缀不变性、吊灯不能同根追高止损、跳空、单向棘轮、倒数阈值边界、替换/叠加及再入场、完整成本权益核对。测试是实现校验，不是收益优势证明。

研究来源是作者提供的私人笔记“量化综述：策略”中的SF01通道式，以及期货择时框架Signals_basic中的KAMA＋滚动ATR版本；仅重写公式与教学实现，没有公开原笔记、第三方框架源码或配置。没有检索到可确认的原框架“波动率倒数退出”完整定义，故以实验定义明确标注。

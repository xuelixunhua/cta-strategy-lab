# 数据与公开发布政策

## 两层仓库

私有研究仓库保存原始研究资料与框架；本项目是独立教学实现。公开项目不复制原框架、配置、私人笔记或Git历史。指标公式、一般交易概念与研究原则用新代码、新说明重写，不把“读到源码”视为获得任意再分发原框架的许可。

## 数据许可与授权

本项目附带的行情来自作者提供的研究快照，具体路径、来源说明及哈希记录在catalog。代码的MIT许可**不覆盖行情**。公开下载接口、个人研究访问权限和向不特定公众再分发，是不同权限。

发布者需确认自身与原始数据提供方的条款，尤其是证券行情、期货采集数据、Yahoo/Tencent/Binance来源。无法确认再分发权限时，不应执行含行情公开发布；可自行保留本地使用，或改用已明确授权的样本。这里没有声称已经完成第三方许可的法律核验。

## 白名单

导出只读取列：时间/日期、OHLC、成交量、必要的合约、调整因子与旧腿开盘。生成的统计结果与行情代理仍可能受到源数据相关协议约束，不能靠改文件格式规避。

不读取或发布：API密钥、登录信息、SSH主机、真实账户、私有配置、订单/持仓、个人信息、原框架代码或Git历史。浏览器端不连接源私有仓库，不接收GitHub令牌，不记录访问者行为；参数和数据都留在浏览器本地。

## 维护

每次更新固定源提交和SHA256、重新导出白名单、运行单元与全数据测试、检查新缺口与换月边界，再更新案例。错误行情不应为得到更好净值而人工平滑；修正应保留明确依据及前后版本差异。

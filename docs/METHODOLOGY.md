# 方法与边界

本项目解释一套**技术交易研究系统**如何构成，不承诺策略有持续优势。趋势跟随只是CTA策略的一类；布林回归是另一种技术交易假设，不能把CTA等同于某一个指标。

## 从指标到系统

SMA、EMA、布林带只描述历史价格。系统还需要明确目标持仓、允许空仓的条件、模拟成交时点、仓位大小、正常退出、保护性止损、成本、区间边界及研究验证。

页面将“为什么入场”“为什么退出”“当时知道什么”与实际结果并列。学习目标是能复述每笔交易，而不是接受一个难以解释的净值曲线。修改规则应当先提出可检验的原因，再用相同口径对照；不能因看见某笔亏损而追加只消除该笔的条件。

## 指标与基础规则

**SMA(N)** 是最近N根已完成K线收盘的算术平均。少于N根不生成完整指标。价格大于均线目标多，小于均线目标空，等于则目标零；只多模式把负目标映射为零。

**EMA(N)** 首次以N根SMA初始化，然后 `EMA_t = α C_t + (1−α) EMA_(t−1)`，`α=2/(N+1)`。保留单SMA的其余规则，便于只观察近期权重变化。相同N不意味着两者完全同样的滤波性质。

**双均线交叉** 用SMA(fast)与SMA(slow)的大小给出方向。它不是“天然更早退出”；两条均线都滞后，多空模式通常持续持仓。

**双均线＋空仓**：快线>慢线且C>快线则多；快线<慢线且C<快线则空；其余零。出场与反手不再绑定，可以在长趋势尚未反转时等待。此实现采用状态条件，退出后次根若重获条件可重新进入；不是仅金叉/死叉那一根才允许入场。

**布林带** 用收盘总体标准差（ddof=0）：中轨SMA(N)，上下轨±Kσ。画在第t根的通道取自第t−1根收盘已确定的结果，突破比较不让当前价扩大自己的门槛。

**布林突破** 空仓时C_t>既定上轨则多，低于下轨则空；多仓C_t<中轨退出，空头对称。正常出场信号不在同一个收盘直接反手，下一次收盘再评价空仓入场。

**布林回归** 前一收盘在其当时通道下轨之外，本根收盘返回既定下轨以上且仍低于中轨则多；上轨方向对称。到达中轨平仓。零波动的通道不交易。回到带内不意味着强趋势结束。

## 信号、执行与窗口边界

第t根收盘产生信号，第t+1根开盘执行。指标可用选定开始日期前的已知历史预热，但选定窗口以现金重新开始，不继承窗口外仓位。未闭合K线是否已被纳入依赖快照来源，本项目不假定实时完整。

窗口最后一根按收盘统一**估值平仓**，计退出摩擦，明确标记 `forced=true`。这是为了对齐完整账目，不是当时已知未来结束的策略信号。交易数和胜率包括这类边界交易；研究可以通过记录辨别其影响。引擎支持 `forceClose=false` 作前缀测试，此时权益包括未平仓浮动盈亏，不能再要求只用已平仓交易净额核对总权益。

行情缺口不补价格。币圈发现小时非正常间隔或日线缺失后，撤销上一旧信号，已有持仓在下一个可观测开盘退出；不能还原缺口内部可能发生的止损。期货休市不算缺失小时；其完整性依赖观测交易日面板，不等于完整官方日历。

零成交量期货K线可展示、可参与指标，但不允许普通模拟成交；下一根重新根据已知条件处理。仅成交量大于零并不能证明有足够深度或涨跌停可成交性。区间末尾仍采用估值平仓，应与真实可成交退出区分。

## 仓位、成本与账目

每次入场按**当时权益×名义仓位比例**配置风险敞口，不在每根K线重置仓位。名义仓位不等于保证金占用。期货数量向下取整为手数；其他标的允许分数单位，是价格代理实验。持仓跨过大幅行情后，敞口/权益会变化，初始100%名义仓位不表示始终维持100%。

教学权益采用线性逐价盈亏账，而非模拟券商账户所有现金、保证金与融资分录。现货/股票代理的多头入场数量按含滑点及手续费的购买总成本计算，因此100%预算不会因入场摩擦被动透支。期货按名义敞口和整数手配置，未模拟历史保证金规则。实盘扩展仍须加入真实可用余额、交割、融资与保证金约束。

模拟成交价 = 参考价 × (1 ± 单边滑点bps / 10000)。买入向更高价、卖出向更低价；期货再向不利方向按最小价位取整。手续费按模拟成交价×数量×乘数×费率，滑点损失按模拟成交价与参考价之差×数量×乘数。

单腿毛盈亏 = 方向×数量×乘数×(原始退出参考价−原始入场参考价)。交易净盈亏 = 各实际腿毛盈亏合计−全部手续费−全部滑点。持仓期权益 = 初始本金＋已实现毛盈亏−累计成本＋未平仓实际腿浮动毛盈亏。估值平仓后，所有交易净盈亏之和与最终权益减本金严格核对。

这是一种避免重复扣减滑点的账法：交易表同时给参考价和含滑点模拟成交价，不能再用含滑点价差算毛盈亏后又扣一遍滑点。

只多为现货默认；开启非期货多空明确属于**未含借券、借贷或永续资金费的理论实验**。超过1倍敞口也只是研究假设。模型在收盘权益耗尽后停止新增交易，但没有模拟盘中强平、历史维持保证金或期货经纪商风控。

## ATR保护性退出

TR = max(H−L, |H−前收|, |L−前收|)。ATR使用Wilder平滑：首次N点均值，此后 `(前ATR×(N−1)+TR)/N`。它与原研究中部分简单滚动ATR并非同一实现，不混用版本。

入场止损依据已知的上一根ATR：多仓为入场信号价格−K×ATR，空头相反。以后每根收盘才用收盘价与ATR推进保护线；多头只上移、空头只下移。第t根的盘中高点不用于生成同根就触发的“事后完美跟踪止损”。

开盘已跳过旧止损线，按更差的开盘价退出；否则盘中触及预先确定的线，按线价加不利滑点成交。保护性止损优先于普通开盘换仓。没有订单簿和涨跌停信息，不能保证真实止损能够按此模型执行。

## 期货连续、复权与换月

源数据是34个实际JM合约，每个最多1,000小时，缺少全历史统一主力标记及完整官方交易日历。实际合约分别提供，不拼接就无需换月复权。

教学连续选择规则：前一交易日**样本内成交量最大**，只向更远到期月份切换。并非持仓量选择，也非官方主力连续；有限历史覆盖可能改变当时的样本可选集合。开始日需要有前一天可决策数据。

换月要求旧、新合约在该交易日首个观测开盘都有真实成交量，并在上一交易日有共同可观测的收盘锚点；不满足则延迟。旧合约不可定价时拒绝虚构移仓并终止连续构建。

设旧衔接比例为F，上一交易日共同锚点的旧、新收盘为P_old和P_new：

```
F_new = F_old × P_old / P_new
Signal OHLC = Raw OHLC × F_current
```

这个**向前递推的比例衔接**只使用当时已知信息，过去的信号价格不因未来换月重写。不要与软件终点固定的“前复权/后复权”中文命名混淆；以公式为准。改变起点可能改变整体显示尺度，交易信号不应随整体比例平移而变化。

实际收益另算：持旧合约到换月时的旧合约真实开盘，平旧合约；同手数开新合约，分别计成本。持仓逻辑可跨换月延续，但记录为多个实际腿。**新旧合约的价格差不是持仓收益，也不是可以直接作为现金成本扣除的“换月损失”。** 基差变化体现在实际持有合约的价格路径中。

已有ATR保护线位于信号价格坐标，换月时须用各自衔接比例映射回真实合约价格。在原始合约图上，所有指标也按相同比例映射，所以仍与K线共享价格坐标；指标线在换月处可以跳动，不应隐藏事实。

## 时间与股票复权

币圈UTC小时保留实际时间标签，包括早期43根非整点记录；日线严格要求24个不同整点小时。缺一天不能用前值填补成“无波动日”。

期货夜盘归属下一**观测日盘交易日**；日线要求合约具备该日面板全部时间点，并要求面板包含9、10、11、13、14点日盘。交易日聚合避免把周五夜盘错误放入周五日线，但它仍不是官方日历校验，不能据此证明所有假日或特殊交易时间正确。

A股指数与美股源只提供日线，不生成小时。股票/ETF将全部OHLC乘以 `adj_close/close`，保持一个一致的调整价格代理；交易表也是该代理价，不假装是历史未复权实际成交价。未独立建模拆股数量变化、分红现金流、税与费用。源提供方对历史调整也可能更新，应固定文件哈希复现。指数不可直接成交，尚未映射为相应ETF或股指期货。

## 指标解释与验证

净收益 = 期末权益/初始本金−1。最大回撤以每根收盘权益相对此前高点计算，初始本金也作为高点基线；**不等于盘中最坏权益回撤**。年化按实际日历时长365.25天幂次换算；短区间不宜外推。夏普先按交易日最后权益形成日收益，标准差采用样本ddof=1，无风险利率设0，币圈乘√365，其他乘√252；少于20日或零方差不报数值。

持仓占比为有风险敞口的K线根数比例，退出开盘那根也计接续持仓暴露；不是严格钟表时长或逐分钟占比。胜率按扣成本后净盈利笔数，盈利因子为净盈利额合计/净亏损额绝对值，无亏损时不能将无穷值当作可持续优势。

MFE与MAE记录每笔交易实际持仓期间的**毛价格路径**最大有利/不利浮动；移仓时累计已实现实际腿毛收益。只在真正持有的K线计高低点；止损K线不计先后顺序无法确定的完整高低点，而计可确认的已实现退出，因此不是完整tick级精确极值。

毛利润回吐 = max(0, MFE−最终毛盈亏)。若最终变成亏损，回吐可能超过此前最大浮盈，比例超过100%并非计算错误。MFE不是当时知道的最高卖点，更不是可全部追回的利润。

持续做多基准使用同一数据、窗口、成本和仓位，不启用ATR；期货同样移仓，且计两边摩擦。它不是策略最优替代方案，只为区分择时贡献与标的方向。

参数研究只缩放周期，K、成本、仓位与ATR保持不变；各段重新从现金开始、用此前历史预热。按完整交易日约70/30切分，防止同日泄露。验证段一旦反复参与选择，就不再是干净的样本外。未实现自动walk-forward寻优、统计显著性检验或组合配置，不将相邻参数表当作策略已通过投资验收。

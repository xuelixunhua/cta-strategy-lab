# 同一突破入场，不同退出方式

本表由v1.1本地引擎对作者提供的实际行情快照运行得到。仓库中的 `node scripts/build_exit_cases.js` 可在数据准备后重现并输出完整参数、哈希和结果JSON。没有为展示寻找最优参数。

## 固定口径

BTC日线，2024-01-01—2026-09-28；布林突破N=20、K=2；只多/空仓；初始本金1,000,000 USDT；入场预算100%；单边手续费3bps、滑点2bps。新退出替换原正常退出；保护退出后等待同方向条件先失效再出现。ATR14、倍数3；吊灯持仓内回看22根；百分比5%；倒数实验基础5%、下限1%、上限20%。区间末尾统一估值平仓。这里显示区间收益而非年化。

## 实际运行结果

| 退出 | 区间净收益 | 最大回撤幅度 | 交易数 |
|---|---:|---:|---:|
| 原策略中轨退出 | 31.58% | 32.21% | 23 |
| 收盘锚定ATR | 57.51% | 31.18% | 16 |
| 吊灯 | 37.70% | 24.49% | 20 |
| 百分比跟踪 | 40.65% | 22.91% | 28 |
| 波动率倒数实验 | 28.22% | 23.25% | 28 |

## 怎样解释

这些数字只描述当前样本，不证明某种退出未来更好。应同时看少回吐、提前离场错失趋势、换手成本和回撤变化。更复杂的波动率倒数规则在这里并没有带来更高区间收益。

这是完整系统对照，不是固定每笔入场价的严格配对实验：退出改变占仓状态，后续实际入场集合也可能改变。已经观察的窗口不能再作为未接触的样本外。

倒数实验为 `clip(基础比例×入场ATR%/当前ATR%, 下限, 上限)`，不是原框架已确认实现，也不是逆波动率仓位。波动放大时候选回撤比例收紧，和ATR距离扩大的机制不同。所有保护线只能在收盘后更新供下一根使用，单向收紧；跳空按更差开盘，不按理想止损线。
